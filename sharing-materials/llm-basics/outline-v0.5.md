## 讲述顺序

| 页码 | 讲述内容 | 预计用时 |
| --- | --- | --- |
| P01–P07 | 先看一条缺依据的报销回答。定位 LLM 和常见 NLP 任务，再比较托管 API 与自行部署。打开 Qwen3-8B 仓库前，辨认开放权重、训练资料和许可证。 | 9 分钟 |
| P08–P16 | 用实际分词和逐步追加演示模型怎样生成。区分训练与推理，再沿配置、权重索引和分词器看模型加载。按 Dense/MoE、位宽、量化版本的顺序读规格，接到推理服务。 | 15 分钟 |
| P17–P24 | 对照预训练、SFT 和 InstructGPT 的人类偏好训练。切到第二轮对话，再回看初次回答缺什么。搭出最小问答应用，比较提示词和整条上下文请求。 | 13 分钟 |
| P25–P30 | 先看 RAG 两阶段，再区分 Token ID 和检索向量，展示召回、重排和条款核对。用两次工具调用取得汇率并完成换算。 | 11 分钟 |

| P39–P43 | 从票据提取字段，梳理模型和程序的分工。展示完整核对说明，按金额、依据和待补项评测，用不存在的条款做排查练习。 | 8 分钟 |
| P44–P45 | 会后查阅参考链接和演示口径。 |  |

## 现场操作

- **P08 分词。** 依次切换中文、英文和代码，找出英文 Token 中的前导空格。
- **P09 生成。** 连续追加 ¥ 和 560，观察第二步比初始输入多出了什么。
- **P19 对话。** 切换到第二轮，指出上一轮的助手回复和本轮生成起点。
- **P30 工具。** 跟完查汇率和做乘法两次往返，确认 636 元来自工具回执。
- **P32 ReAct。** 到第四步切换审批记录。缺件时交付待补说明，有记录时进入核验。

P24 的讲稿保留完整 vLLM 请求体。PDF 展开三类分词、追加步骤、工具往返与审批分支。 [制作及重建说明](v0.5/README.md)
