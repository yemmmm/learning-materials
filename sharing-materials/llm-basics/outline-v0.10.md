# 大模型常见概念

v0.10 · 2026-11-19。面向无需机器学习背景的 IT 同事。主讲约 65 分钟，另留交流时间。 [离线演示](exports/llm-basics-slides-v0.10.html) · [PDF](exports/llm-basics-slides-v0.10.pdf) · [逐页讲稿](exports/llm-basics-speech-v0.10.md)

## 讲述顺序

- **P01–P05** 从 AI、深度学习和 NLP 到现代 LLM，认识托管 API、自行部署和公开模型仓库。
- **P06–P12** 看真实词表和权重分片，理解分词、自回归生成、结构与权重及模型规格。
- **P13** 用翻译对照模型的训练和推理，说明权重怎样从训练产物进入推理服务。
- **P14–P17** 比较预训练、监督微调和偏好对齐。用翻译理解多轮对话，用会议通知说明提示词，最后看一次完整请求。
- **P18–P21** 跟完 RAG 的召回、重排和作答。以故障描述理解 Embedding，再看一次汇率换算调用。
- **P22–P28** 用提交报销申请展示 Workflow 和 ReAct，再讲 Harness。用构建排查解释任务记忆、上下文压缩以及 Tool、MCP 和 Skill。
- **P29** 比较八类非 LLM 模型，加入 Seedance 2.5 的视频生成示例。
- **P30** 从答案质量、任务完成、安全、时延、容量与稳定性、成本评价大模型应用。
- **P31** 回顾已讲概念，按模型与模态、训练与对齐、生成与推理、推理加速、知识检索、Agent 编排、评测与观测、安全与治理选讲。
- **P32–P33** 参考资料与演示口径。

## 现场操作

- **P06 分词。** 对照英文样例与 `vocab.json`，再切换中文和代码。
- **P07 自回归生成。** 依次追加 `pending`、句号和结束符。
- **P15 对话。** 先指出监督微调样本中的输入与参考答案，再切到第二轮，找到上一轮译文和本轮开始续写的位置。
- **P21 单次换算。** 看一次 `convert_currency` 请求怎样得到汇率和换算金额。
- **P23 提交申请。** 在检查审批时切换有无记录，再查看待补或提交结果。

P17 的讲稿保留完整 vLLM 请求体。 [制作与重建说明](v0.10/README.md)
