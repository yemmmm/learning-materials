# 大模型常见概念

v0.7 · 2026-11-19。面向无需机器学习背景的 IT 同事。用一笔住宿 560 元、另有 120 新币费用的报销案例贯穿分享。主讲约 70 分钟，另留交流时间。 [离线演示](exports/llm-basics-slides-v0.7.html) · [PDF](exports/llm-basics-slides-v0.7.pdf) · [逐页讲稿](exports/llm-basics-speech-v0.7.md)

## 讲述顺序

- **P01–P05** 从 AI 的技术层级和 NLP 任务讲到生成式大语言模型，再看使用方式和 Qwen3-8B 仓库。
- **P06–P13** 用真实词表解释分词，演示自回归生成和结束符。对照结构配置与权重分片，再读模型名称、Dense/MoE 和量化规格，跟着权重从训练进入推理服务。
- **P14–P17** 比较预训练、监督微调和偏好对齐，解释续写模型如何成为对话助手，再看提示词和上下文请求。
- **P18–P21** 用一张 RAG 图跟完提问、召回、重排序、组装上下文和输出回答。先认识文本 Embedding，再比较 Token ID，随后跟完两次工具调用。
- **P22–P29** 比较固定流程与 Agent，切换审批记录观察 ReAct 分支，再讲 Harness、MCP 与 Skill。
- **P30–P34** 从票据提取字段，用完整核对说明结束案例，再按金额、依据和待补项评测。
- **P35–P36** 参考资料与演示口径。

## 现场操作

- **P06 分词。** 对照英文样例与 `vocab.json`，再切换中文和代码。
- **P07 自回归生成。** 依次追加 `pending`、句号和结束符，观察每一步怎样使用刚生成的内容。
- **P15 对话。** 切到第二轮，指出上一轮的助手回复和本轮开始续写的位置。
- **P21 工具。** 跟完查汇率和做乘法两次往返，确认 636 元来自工具回执。
- **P23 ReAct。** 到第四步切换审批记录，比较缺件时交付待补说明与有记录时继续核验。

P17 的讲稿保留完整 vLLM 请求体。 [制作与重建说明](v0.7/README.md)
