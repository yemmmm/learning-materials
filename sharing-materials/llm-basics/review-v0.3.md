# 大模型基础演示稿 v0.3 审阅

2026-11-18。按面向 IT 同事、无需机器学习背景、约 60–70 分钟的小组分享评估。逐页看过 48 页 PDF 的渲染，对照讲稿，并在 1280 × 720 的 Chromium 中切换了五个离线演示。讲述节奏为估算。 [v0.3 PDF](exports/llm-basics-slides-v0.3.pdf) · [离线 HTML](exports/llm-basics-slides-v0.3.html) · [讲稿](exports/llm-basics-speech-v0.3.md)

## 总体结论

从模型生成、对话请求、资料与工具到 Agent 的顺序成立。分词接生成、聊天模板接上下文、工具往返接自主决策的过渡都值得保留。原稿将文件细节和规格集中在 P11–P17，现场容易暂时丢掉开场的差旅问题。后段 P41–P44 连续使用四张表，P43 的交付示例只占页底一行，结尾的视觉重心落在组件清单。

新版先展示一条缺依据的报销回答，再逐步补齐证据与执行能力。32 页进入主讲，其余作为选讲和参考。模型规格选讲中，先解释 Dense 与 MoE，再读 30B/A3B 和量化格式。后半把主要版面留给上下文窗口、工具结果、Agent 反馈和最终核对说明。 [v0.4 大纲](outline-v0.4.md)
