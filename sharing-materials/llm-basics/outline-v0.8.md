## 讲述顺序

- **P01–P05** 从 AI 的技术层级和 NLP 任务讲到生成式大语言模型，再看使用方式和 Qwen3-8B 仓库。
- **P06–P13** 用真实词表解释分词，演示自回归生成和结束符。对照结构配置与权重分片，再读模型名称、Dense/MoE 和量化规格。
- **P14–P17** 比较预训练、监督微调和偏好对齐，解释续写模型如何成为对话助手，再看提示词和上下文请求。
- **P18–P21** 用 RAG 图跟完召回、重排和作答，介绍文本 Embedding，再演示一次 Function Calling。
- **P22–P28** 以提交报销申请为目标，比较固定流程与 Agent，用 ReAct 展示待补和提交两条分支。接着解释 Agent 中 LLM 与 Harness 的分工，以及 Tool、MCP 和 Skill 的用途。
- **P29–P34** 从票据提取字段，展示缺件分支的核对说明，回顾整项任务怎样评测和排查。最后介绍推理服务的常见指标。
- **P35–P36** 参考资料与演示口径。

## 现场操作

- **P06 分词。** 对照英文样例与 `vocab.json`，再切换中文和代码。
- **P07 自回归生成。** 依次追加 `pending`、句号和结束符。
- **P15 对话。** 切到第二轮，指出上一轮的回复和本轮开始续写的位置。
- **P21 单次换算。** 确认模型只提出一次 `convert_currency` 调用，工具返回汇率和换算金额。
- **P23 提交申请。** 第四步选择审批材料，再看第五步的提交结果。缺件时保存草稿，有记录且核验通过时展示教学申请单号。

P17 的讲稿保留完整 vLLM 请求体。 [制作与重建说明](v0.8/README.md)
