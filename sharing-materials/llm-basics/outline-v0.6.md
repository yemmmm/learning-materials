# 大模型常见概念

v0.6 · 2026-11-19。面向无需机器学习背景的 IT 同事。用一笔住宿 560 元、另有 120 新币费用的报销案例贯穿分享。主讲约 70 分钟，另留交流时间。 [离线演示](exports/llm-basics-slides-v0.6.html) · [PDF](exports/llm-basics-slides-v0.6.pdf) · [逐页讲稿](exports/llm-basics-speech-v0.6.md)

## 讲述顺序

- **P01–P05** 从 AI 的技术层级和 NLP 任务讲到生成式大语言模型。沿 NLP 发展中的几个节点进入模型使用方式和 Qwen3-8B 仓库。
- **P06–P13** 对照真实词表理解分词，跟到模型生成结束符。用简化神经网络区分结构与权重，再读模型名称、Dense/MoE 和量化规格，接到部署与推理。
- **P14–P17** 比较预训练、监督微调和偏好对齐。看续写模型怎样在助手轮次回复，再从一条提示词扩展到完整的上下文请求。
- **P18–P23** 用图看制度怎样切片入库，收到问题后怎样找回片段并放入上下文。区分 Token ID 与检索向量，演示重排、引用核对和两次工具调用。
- **P24–P31** 比较固定流程与 Agent，切换审批记录观察 ReAct 分支，再讲 Harness、MCP 与 Skill。
- **P32–P36** 从票据提取字段，用完整核对说明结束案例，再按金额、依据和待补项评测。
- **P37–P38** 参考资料与演示口径。

## 现场操作

- **P06 分词。** 对照英文样例与 `vocab.json`，再切换中文和代码。
- **P07 生成。** 依次追加 `pending`、句号和结束符，观察何时停止。
- **P15 对话。** 切到第二轮，指出上一轮的助手回复和本轮开始续写的位置。
- **P23 工具。** 跟完查汇率和做乘法两次往返，确认 636 元来自工具回执。
- **P25 ReAct。** 到第四步切换审批记录，比较缺件时交付待补说明与有记录时继续核验。

P17 的讲稿保留完整 vLLM 请求体。 [制作与重建说明](v0.6/README.md)
