## 风格描述

**简约手绘业务概念图**：暖白纸底、深灰墨线，以少量灰蓝和赭黄点色。线条略带自然手绘感，中文字形清晰规整。用宽松留白和少量关系节点讲清概念，适合业务、产品与技术混合受众。

参考 baoyu 的 `sketch-notes`，收敛为更克制的商务教学风格。关系图明确标注“教学示意”，不代表真实运行模型或验收结论。
