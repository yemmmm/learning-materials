# 单页试绘分析

- 主题：本体论如何帮助 Agent 理解与处理业务。
- 输入：`docs/presentations/2026-10-12-ontology-agent-ppt-text-draft.md`，2026-10-12 版，22 页。
- 受众：业务、产品与技术混合受众，部分观众没有 Agent 开发经验。
- 语言：简体中文，保留 Ontology、Agent、SLA 等原有术语。
- 本次范围：只制作草稿第 5 页的一个样张，供用户判断视觉效果，不生成其余 21 页。
- 选择理由：第 5 页覆盖核心概念，文字与五节点关系图并存，能检验中文可读性、线条、色彩和信息密度。
- 核心信息：本体用明确的概念、关系和语义约定组织业务知识。
- 视觉风格：基于 baoyu `sketch-notes` 收敛的“简约手绘业务概念图”。暖白纸底、深灰细墨线、灰蓝与赭黄少量点色；轻微手绘不规则，规整清晰的中文手写字，大量留白。避免儿童卡通、密集涂鸦与复杂纸纹。
- 比例：16:9。
- 图像后端：Codex 内置 imagegen。
- 授权：用户明确要求自行判断风格、选择一页并生成；据此执行单页试绘，风格确认点保留在样张交付后。
- 图的边界：概念关系为教学示意，不代表真实运行模型或业务验收结果。
- 输出形式：PNG、单页 PPTX、单页 PDF，以及源稿、风格描述与可复现提示词。

## 制作范围

保留第 5 页的定义、业务概念地图比喻、概念与关系、SLA 定义与适用范围、未知问题。把原来的长问题压缩为短问句，五个概念旁保留简短解释。演讲备注保留入门比喻与形式化推理的区别。
