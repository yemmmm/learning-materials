## 页序判断

采纳将 RDF/OWL 紧接三层区分的建议：**P04「现实世界、本体、形式表达」→ P05「RDF 与 OWL 分别做什么」**。先回答“属于哪一层”，随即回答“这两种技术做什么”，再认识组成与推理。

1. **问题与本体（P01–P09）**：具体问题 → 本体定义 → 三层区分 → RDF/OWL → 常见组成 → 推理与检查 → 知识图谱与事实 → 相关技术速览。
2. **两条 AI 路线（P10–P12）**：符号主义与联结主义 → 专家系统 → 优势与代价。
3. **Agent 的使用（P13–P15）**：如何组合能力 → 一次完整审批推演 → 跨任务复用与投入判断。
4. **建设与平台（P16–P18）**：如何建一个有用的本体 → OntoWeave 的职责 → 实际界面。
5. **收束与答疑（P19–P22）**：三句话结束主讲，随后按现场问题使用 FAQ。

技术速览保持一页、一分钟左右，不展开语法。放在知识图谱之后，听众已有“图、定义、事实”的基础，随后转向 AI 路线与 Agent。
