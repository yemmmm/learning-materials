## 本次修订

1. **P17 重绘平台架构。** 以业务人员 → 建模 Agent → 语义知识与平台服务 → 业务 Agent 的关系展开。建模 Agent 使用独立深绿色模块，突出理解资料、澄清、组织模型、提交变更和读回自查。外部业务系统独立放置，明确真实查询和业务操作的承担方。
2. **P18 新增平台能力。** 四项能力分别是 Agent 辅助建模、多视角组织知识、按任务获取语义、浏览与持续维护。底部用差旅场景串起输入、形成的模型和供给业务 Agent 的语义。
3. **P19 展示实际界面。** 原 P18 截图与解释保留并后移；删除原 P19 独立收束页，将自然结束语并入截图页讲稿。平台介绍按“架构 → 能力 → 界面”展开。
4. **技术速览紧接 RDF/OWL。** P04 三层区分 → P05 RDF/OWL → P06 SKOS、SWRL、OWL-S、SPARQL 速览；其后依次是组成、推理与知识图谱。
5. **重写本体与知识图谱页。** P09 用员工、部门等概念与张三、研发部等具体知识的对应，说明本体可作为知识图谱的语义模型。删除负责人变更交互，讲稿和 FAQ 对应回答同步。
6. **同步口述讲稿与导航。** 22 页提供面向观众的完整讲述和过渡；HTML 讲稿、独立 Markdown、页码、目录、章节及 FAQ 返回链接一致。`speaker-notes` 保留为完整演讲稿的同内容入口。

## 内容与平台表述

平台页依据当前需求中的直接建模提交、确定性校验与应用、受治理语义读取来描述职责；建模 Agent 的自查属于建模过程，不能代替独立质量验证。平台图是产品能力示意，不是部署拓扑。

OWL 自动推理、SHACL 与专用规则执行仍只在通用技术知识范围内讨论，不作为 OntoWeave 当前平台承诺。模型中的行为与接口映射用于表达业务知识，真实业务操作由外部系统执行。截图中的节点、关系数量仅代表当时界面状态。

## 交付与使用

- HTML：字体、截图、样式、交互和讲稿全部内嵌，可离线打开。
- PDF：22 页，展开全部内容和 FAQ，保留默认教学事实。
- 演讲稿：22 页完整口述稿，参考资料集中在末尾；主讲约 30 分钟，FAQ 按需使用。
- 内容审阅稿：逐页文字，便于修改与对照。
- ZIP：以上发布文件、修订说明、阅读说明与第三方许可。

方向键／空格翻页；`G` 目录、`N` 讲稿、`S` 分步、`A` 展开本页、`F` 全屏。点击截图可放大。手机支持横向滑动，建议横屏。
