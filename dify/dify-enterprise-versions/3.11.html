3.11.x Latest

3.11 是 Dify 企业版的最新能力线。3.11.0 引入了工作区 RBAC 角色权限、difyctl 命令行客户端、CoT 推理可视化等重磅能力（需停机 + 强制迁移）； 3.11.1 则带来了实时多人工作流协作编辑，是当前最新发布版本。对应社区版 1.15.0。

8 新特性
RBAC：工作区角色权限控制★ 重磅 · 权限
工作区现在支持细粒度角色权限控制（RBAC）。管理员可定义自定义角色和权限集，分配资源级访问（应用、知识库、工具、凭据、监控），并从工作区 UI 和企业管理台双向管理角色分配。包含：系统预设角色、多语言角色/权限模板、资源默认访问策略、按资源 ACL。关闭 RBAC 时回退到旧的固定角色行为。
difyctl：命令行客户端CLI · 效率
新增命令行客户端，无需 web UI 即可直接从终端调用应用和工作流。支持 macOS、Linux、Windows，发布带校验和（checksum）验证。
CoT 思维链推理可视化推理模型 · 体验
聊天流和工作流现在可把模型推理过程流式输出到专门的"思考"面板，同时保持最终答案干净。推理内容跨页面刷新持久化，并在 CLI 和工作流预览中一致显示。
HITL：下拉选择与文件上传HITL · 表单
工作流暂停表单在文本输入之外，现在还支持下拉选择和文件上传，审核者可在人工审核步骤给出结构化响应并附带文件。
长时模型支持工作流 · 多模态
工作流现在通过轮询容纳慢模型（如图像、视频生成），等待结果而非超时失败。
知识导入：Excel 内嵌图片提取知识库 · RAG
知识导入现在会提取 Excel 文件内嵌的图片，此前被丢弃的图示类内容得以保留进知识库。
可观测性：自定义追踪会话 ID 与检索追踪可观测性
用户可为 Phoenix 设置自定义追踪会话 ID，文档检索步骤现在也可追踪，提升 RAG 透明度。
社区版 1.15.0 基础基线升级
本版本将 Dify 基线升级到社区版 1.15.0，所有上游 1.15.0 的特性与修复都纳入企业发行版。
2 问题修复
安全CVE-2026-41948：修复插件守护进程请求转发中的路径遍历漏洞（继承自社区版 1.15.0 基线）。
稳定性工作流与 RAG 稳定性改进：加固 HTTP 超时、修复向量库兼容性问题、细化工作流执行错误处理，并降低工作流启动与终止延迟。
! 升级影响（破坏性 · 必须迁移，否则宕机）
⚠ 本版本需停机，且必须运行数据库迁移——迁移完成前应用不可用：

迁移未完成时：工作区成员没有 RBAC 角色（拒绝访问）、数据集权限未映射到 RBAC、插件自动升级状态未初始化。请安排维护窗口，升级后立即运行全部迁移、再恢复流量。

• RBAC 成员角色迁移（必须）：flask rbac-migrate-member-roles。不运行则现有成员映射不到任何 RBAC 角色、全工作区访问被拒，应用实质宕机。

• RBAC 数据集权限迁移（必须）：flask rbac-migrate-dataset-permissions --apply。不运行则旧数据集权限（all-team / partial-members / only-me）未映射到 RBAC，知识库访问错误。

• 插件自动升级回填（必须）：flask backfill-plugin-auto-upgrade，为既有安装初始化插件自动升级状态。

2 新特性
工作流协作：实时多人编辑★ 重磅 · 协作
实时多人工作流编辑在企业版正式可用（GA）。多名编辑者可通过专用 Socket.IO websocket 服务同时编辑同一个工作流。协作通过 Helm 的 collaboration.enabled 开关启用，需 Dify 企业版 3.11.1 或更高版本。
Admin API：RBAC 支持Admin API · 自动化
企业 Admin API 现在支持 RBAC，可通过 Admin API 编程管理工作区成员角色与权限（除控制台 UI 之外的又一条路径），便于自动化配置管理。
6 问题修复
安全SQL 注入加固（加固查询构造 + 元数据 key 校验，关闭继承自社区版的注入向量）；CVE 依赖修复（python-socketio / python-engineio / soupsieve，插件守护进程 Go builder 升级）。
RBAC编辑者权限修正：编辑者不再尝试成员管理、可查看应用日志、改 trace 配置现需编辑权限；成员新建的应用默认对同角色成员可访问。
插件插件管理稳定性：marketplace 安装回调、debug 模式插件权限未生效、插件外部 user ID 解析、凭据刷新改为 single-flight；内置对象存储启用 HTTP Range，修复 >5MB 插件安装失败。
工作流/API修复 Working outside of application context、分块工作流失败追踪数据、批量记录删除无限循环防护、内部 RBAC 请求接入专用超时。
UI/认证主导航状态、数据集创建布局高度、应用卡片溢出、无插件时深色模式渲染、HITL 输入保存按钮可见性、toast 阻塞点击、OAuth 错误、重复 auth 前缀、管理成员页过滤后分页。
